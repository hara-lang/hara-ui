# `@hara-lang/ui-tool`

The independently publishable Hara tool/workbench layer. It composes the
foundation styles from `@hara-lang/ui` and provides Astro components for tool
bars, workbenches, inspectors, runtime panels, and environment views.

```astro
---
import "@hara-lang/ui/v2.css";
import "@hara-lang/ui-tool/v2-tool.css";
import WorkbenchShell from "@hara-lang/ui-tool/astro/v2/WorkbenchShell.astro";
---
```
